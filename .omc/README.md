# OMC local state (taking_care_server)

Estado local de orquestracao para o pacote Node `taking_care_server/`.

## Stack alvo

- Node.js + Express + Sequelize
- Evolucao recomendada para TypeScript

## Especializacao esperada nos agentes OMC

- Node.js + TypeScript
- React + Vite + Tailwind CSS v4 (quando task envolver frontend web)
- FastAPI + Pydantic (quando task envolver backend Python)

## Fluxo deste pacote

- Executar scripts via npm no host.
- Validar input e tratamento de erro em endpoints.
- Preferir mudancas pequenas e com baixo risco.
